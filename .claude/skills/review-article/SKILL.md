# 기존 문서 상호평가 하네스

기존 문서를 `docs/EDITORIAL.md` 루브릭으로 채점하고, 게이트 미달분을
수정하는 스킬입니다.

## 절차

1. 대상 슬러그의 소스(`src/content/articles/<slug>.html`)를 확인한다.
   "all"이면 `order.json` 순서대로 전부.

2. **문서마다** 패널을 구성해 **병렬 실행**한다:
   - 분야 도메인 페르소나 1인 (로스팅→persona-roaster, 추출/장비→
     persona-barista, 센서리→persona-q-grader, 산지/생두→persona-farmer,
     커피 기초→가장 가까운 도메인 1인)
   - `persona-writer` (문체·구조)
   - `persona-interviewer` (근거 심문)
   여러 문서를 검토할 때는 문서 단위로 배치를 나눠 순차 진행(동시 에이전트
   과다 방지).

3. **집계**: 문서별로 패널 점수를 축별 평균내 표로 정리한다.
   게이트(전 축 ≥3, 평균 ≥4.0) 통과 여부를 판정한다.

4. **수정**: 게이트 미달 문서만, 심각도 높음 지적부터 파일을 직접 수정한다.
   사실 관련 지적 중 출처가 필요한 것은 `research-librarian`으로 검증 후
   반영한다. 수정 후 해당 축 페르소나만 재실행해 재채점받는다.

5. **마감**: `npm run build:content && npm run check-content` 통과 확인 후,
   문서×축 점수표 + 수정 내역 + 미해결 쟁점을 보고한다. history 프론트매터에
   수정 이력을 추가한다("패널 리뷰 반영: ..."). 커밋은 사용자 요청 시에만.

## 규칙

- 점수를 좋게 보이려고 지적을 무시하지 않는다. 기각한 지적은 기각 사유를
  보고에 남긴다.
- 원문의 목소리(문체)를 유지한 최소 수정을 우선한다.
