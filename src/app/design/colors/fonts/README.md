# LINE Seed Sans KR

`LINESeedKR-Bd.woff2` is the Bold webfont from LINE Seed Sans KR, used only
for the public color names on `/design/colors`.

- Source: <https://seed.line.me/>
- Copyright: LY Corporation
- License: SIL Open Font License 1.1
- Original package: `LINE_Seed_Sans_KR.zip`, release dated 2023-09-06

The official source describes LINE Seed as a geometric typeface that combines
simple forms, clear curves, rounded corners, friendliness, and legibility.
The font is not modified or resold.
