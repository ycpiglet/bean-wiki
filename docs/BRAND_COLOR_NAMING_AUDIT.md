# Bean Wiki 브랜드 컬러 네이밍 아카이브

이 문서는 공개 팔레트에서 실제로 사용했던 이름을 빠짐없이 보존하고, 현재
선정안의 판단 근거를 기록하는 내부 아카이브다. 공개 카탈로그의 정본은
`src/design/brand-colors.json`이다.

## 취향 기준

- 산지명만 단독으로 쓰지 않고 `그린빈`, `커피 체리`, `실버그린`처럼 눈에
  보이는 대상을 붙인다.
- `강력분`, `딸기잼` 같은 번역형 표제보다 `브레드 플라워`,
  `스트로베리 잼`처럼 카페 메뉴와 패키지에서 익숙한 외래어 조합을 쓴다.
- `Spent`, `Open Crumb`, `Frangipane`, `Ceremonial`처럼 이름을 무겁게 하는
  전문 수식어는 색을 구분하는 데 꼭 필요하지 않으면 이야기로 내린다.
- 이름을 글자 수로 잘라 맞추지 않는다. 데스크톱 4열 카드에서 실제 한 줄로
  보이는지를 브라우저로 측정하고 글자 크기와 카드 폭을 조정한다.
- 산지·품종·등급은 색의 공식 근거가 아니다. 친숙한 검색 표제로 사용할 때는
  실제 관찰 대상과 한계를 카드 설명에 적는다.

## 채택·제외 판단

- 복원: `브라운 슈거 로스트`, `다크 초콜릿 크랙`,
  `에스프레소 크레마 골드`, `포터필터 핸들 블랙`,
  `로스터스 에이프런 그린`, `스테인리스 피처 실버`,
  `콘크리트 카운터 그레이지`, `오일드 오크 카운터`.
- 재구성: 짧아지며 대상을 잃었던 산지명에는 `그린빈`, `커피 체리`,
  `실버그린`, `스트로 골드`를 다시 붙였다.
- 재표기: `강력분 화이트`는 `브레드 플라워 화이트`로,
  `딸기잼 레드`는 `스트로베리 잼 레드`로 바꿨다.
- 유지 제외: `카스카라 인퓨전 로즈`, `스웨디시 펄 슈거 화이트`,
  `레몬 필 옐로`, 소금·화산토·마키아토 블랙 계열은 소재 친숙도 또는
  색상 정합성이 낮아 복원하지 않았다.
- 과학적 주석: `Kenya AA`는 생두의 크기 등급이므로 `케냐 AA 커피 체리`는
  친숙한 시장 라벨과 케냐의 익은 체리 장면을 결합한 브랜드명이다. AA 자체가
  체리 품종이나 색을 뜻하지 않는다는 설명을 공개 카드에 유지한다.
