Development is not only the period after first crack

In practice, teams often call the period from first crack onset to discharge “development time.” It is useful in communication, but flavor-forming reactions continue across the full roast, not only after first crack.

Therefore development ratio should be used with charge conditions and energy context, not as a single quality target.

Stage-level purpose during roasting

  • Drying stage: moisture removal and heat normalization set the baseline; instability here usually spreads to later outcomes.
  • Maillard stage: color and sugar-derived transitions accelerate, then feed into later flavor perception.
  • Development stage: post-crack tailing behaviors shape acidity, body, and bitterness balance.

Track stage transitions before final duration; this reduces overheat/underheat variance much faster than changing one value late.

Signals to log together

The displayed temperature is affected by probe placement and response speed. Record color, aroma, crack pattern, exhaust, and physical signs together for better batch comparison.

Operational decision frame

  1. Set flavor goal: define whether acidity, sweetness, or body is the first priority.
  2. Fix variables: change only one control at a time.
  3. Verify: roast the same lot with repeated extractions and compare the same taste checkpoints.
  4. Lock settings: keep the setting if sensory spread narrows.

Practice: 3-batch stabilization loop

  1. Set one baseline profile and roast three batches of the same lot first.
  2. Log only crack timing, development ratio, and taste notes each batch.
  3. Compare first two batches; adjust only one axis in batch three.
  4. Move the next axis only after acidity, body, and bitterness tighten together.
